Setup Instructions

  1. Open js/config.js and paste your Supabase project URL and anon public key.
  2. Run sql/schema.sql and sql/auth_and_economy.sql in Supabase SQL Editor.
  3. In Supabase, go to Authentication → Providers and enable GitHub and Discord.
  4. Paste GitHub and Discord OAuth credentials into each provider.
  5. Go to Authentication → URL Configuration → Redirect URLs and add:
    https://pinkfrog2.github.io/csweb/
  6. Done! The app will show GitHub and Discord login buttons.
